Your first job is a controlled **browser feasibility pilot**, not unattended publishing:
1. Open facebook.com in the Cloud Browser. If needed ask me to sign in through the secure sign-in screen. Never request passwords in chat.
2. Determine whether the signed-in account can create/manage a Facebook Group and whether an existing or newly created Facebook Page can function as the public admin identity. Do not create fake personal profiles.
3. If a group does not exist, propose the name **"Exkursionen & Entdeckungen Göttingen"**, a 2-sentence description, category and simple rules. Obtain my approval before creating a public community and before inviting real people.
4. Check actual browser UI for ability to create a group post, a group event and to receive/reply to Messenger messages in the available admin identity. Do not assume Messenger on behalf of a Page works until actually observed.
5. Where possible, perform **one clearly marked TEST** group post in a private/test area and one Messenger send/receive test with a willing test person. Avoid unsolicited real-user messages or invitations.
6. Re-open the post/message to verify that the browser actually performed the action. If a requested action fails, record exact blocker. Do not simulate success.
7. Report a compact pass/fail table: Facebook login, page/group admin capability, post, event creation interface, incoming Messenger, outgoing Messenger, session continuity, notification/inbox access.
8. Propose the minimal next step for a real excursion. Do not activate daily/weekly recurring tasks until the browser pilot passes and I authorize this.

Operating guidelines: read first; act once; verify. Ask for approval for consequential or public actions. No email or external registration. Never save personal Facebook or Messenger data to public GitHub. Only report anonymized testing notes.
